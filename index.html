02 · PROMPT STRUCTURE

องค์ประกอบของ Prompt

ROLE

คุณคือผู้เชี่ยวชาญด้าน Microsoft Excel และ VBA

INSTRUCTION

ช่วยเขียน VBA Macro สำหรับจัดกลุ่มและแยกข้อมูลจาก Worksheet ปัจจุบัน โดยมีเงื่อนไขดังนี้

CONTEXT

วัตถุประสงค์: ต้องการแยกข้อมูลออกเป็นหลาย Worksheet โดยอ้างอิงค่าจาก Column B ข้อมูลต้นทาง: 1. แถวแรกเป็น Header และต้องคัดลอก Header ไปยังทุก Worksheet ที่สร้างใหม่ 2. ตรวจสอบข้อมูลตั้งแต่แถวที่ 2 จนถึงแถวสุดท้ายที่มีข้อมูล

CONSTRAINT

3. นับจำนวนแถวของแต่ละค่าที่ไม่ซ้ำกันใน Column B 4. หากค่าใน Column B ค่าใดมีจำนวนตั้งแต่ 20 แถวขึ้นไป: - ให้สร้าง Worksheet แยกสำหรับค่านั้น - คัดลอกข้อมูลทั้งแถวของรายการที่มีค่า Column B ตรงกันไปยัง Worksheet ดังกล่าว 5. หากค่าใน Column B ค่าใดมีจำนวนน้อยกว่า 20 แถว: - ให้นำข้อมูลทั้งหมดไปรวมไว้ใน Worksheet ชื่อ "ETC" 6. ต้องคัดลอกข้อมูลทุก Column ของแถวนั้น ไม่ใช่เฉพาะ Column B 7. ห้ามแก้ไขหรือลบข้อมูลใน Worksheet ต้นฉบับ 8. หากมี Worksheet ชื่อเดียวกันอยู่แล้ว ให้ลบ Worksheet เก่าแล้วสร้างใหม่ หรือเคลียร์ข้อมูลก่อนเขียนใหม่ 9. ชื่อ Worksheet ต้องไม่เกิน 31 ตัวอักษร และต้องตัดอักขระที่ Excel ไม่อนุญาต ได้แก่ \ / ? * [ ] : 10. หาก Column B เป็นค่าว่าง ให้นำรายการนั้นไปรวมไว้ใน Worksheet "ETC" 11. ปรับความกว้าง Column ในทุก Worksheet ใหม่ให้พอดีกับข้อมูลด้วย AutoFit 12. ต้องรองรับข้อมูลจำนวนมากและทำงานอย่างมีประสิทธิภาพ โดยปิด ScreenUpdating และ Calculation ชั่วคราว 13. เมื่อทำงานเสร็จ ให้เปิดการตั้งค่าทั้งหมดกลับคืน แม้เกิดข้อผิดพลาด 14. แสดงข้อความสรุปเมื่อทำงานเสร็จว่า: - สร้าง Worksheet ใหม่กี่ชีต - มีข้อมูลรวมใน ETC กี่แถว - ใช้เวลาประมวลผลกี่วินาที

FORMAT

กรุณาส่งผลลัพธ์ดังนี้: 1. VBA Code ที่พร้อมนำไปวางใน Module และใช้งานได้ทันที 2. ขั้นตอนติดตั้งและวิธีรันแบบละเอียดสำหรับผู้ที่ไม่มีความรู้ VBA 3. อธิบายส่วนสำคัญของ Code 4. ระบุข้อจำกัดและสิ่งที่ควรตรวจสอบก่อนใช้งาน 5. ตรวจสอบให้แน่ใจว่า Code มี Error Handling และไม่มีการใช้ Select หรือ Activate โดยไม่จำเป็น

02 · PROMPT STRUCTURE PROMPT
UPDATED VERSION
ROLE
คุณคือผู้เชี่ยวชาญด้าน Microsoft Excel และ VBA
INSTRUCTION
ช่วยเขียน VBA Macro สำหรับจัดระเบียบและแยกข้อมูลจาก Worksheet ปัจจุบันออกเป็นหลาย Worksheet โดยอ้างอิงค่าจาก Column B ตามเงื่อนไขต่อไปนี้
CONTEXT
1. แถวแรกเป็น Header และต้องคัดลอกไปยังทุก Worksheet ที่สร้างใหม่
2. ตรวจสอบข้อมูลตั้งแต่แถวที่ 2 จนถึงแถวสุดท้าย โดยพิจารณา Column A:L
- หาก A:L ว่างทั้งหมด ให้ข้ามแถวนั้น
- หากมีข้อมูลอย่างน้อย 1 Column ในช่วง A:L ให้ถือเป็นแถวข้อมูล แม้บาง Column จะว่าง
CONSTRAINT
3. Sort ข้อมูลทั้งแถวใน Worksheet ต้นฉบับแบบ A–Z โดยใช้ Column A เป็นหลัก ไม่นำ Header มารวม และจัดแถวข้อมูลให้ต่อเนื่องโดยไม่มีแถวว่างตามเงื่อนไขข้างต้นคั่น
4. หลังจาก Sort ให้นับจำนวนแถวของแต่ละค่าที่ไม่ซ้ำกันใน Column B แล้วแยกข้อมูลดังนี้:
- ตั้งแต่ 20 แถวขึ้นไป: สร้าง Worksheet สำหรับค่านั้น
- น้อยกว่า 20 แถว: รวมไว้ใน Worksheet ชื่อ "ETC"
- Column B ว่าง: รวมไว้ใน Worksheet "ETC"
- คัดลอกข้อมูลทุก Column ของแต่ละแถวไปยัง Worksheet ปลายทาง
5. ห้ามลบหรือแก้ไขข้อมูลใน Worksheet ต้นฉบับ
ยกเว้นการเปลี่ยนลำดับแถวจากการ Sort
6. หากมี Worksheet ปลายทางชื่อเดียวกันอยู่แล้ว ให้ลบและสร้างใหม่ หรือเคลียร์ข้อมูลเดิม โดยต้องไม่กระทบ Worksheet ต้นฉบับ
7. ชื่อ Worksheet ต้องไม่เกิน 31 ตัวอักษร และต้องไม่มีอักขระ \ / ? * [ ] :
8. ปรับความกว้าง Column ของทุก Worksheet ที่สร้างใหม่ให้พอดีกับข้อมูล
9. Code ต้องรองรับข้อมูลจำนวนมาก ทำงานได้รวดเร็ว และใช้หน่วยความจำอย่างเหมาะสม โดยต้องไม่ลดความครบถ้วนหรือความถูกต้องของข้อมูล
10. เมื่อทำงานเสร็จหรือเกิดข้อผิดพลาด ต้องคืนค่าการตั้งค่า Excel ที่เปลี่ยนไว้กลับเป็นค่าเดิม
11. ชื่อชุดคำสั่ง ฟังก์ชัน ตัวแปร และคำอธิบายใน Code ให้เป็นภาษาอังกฤษ ส่วนข้อความที่แสดงหลังรันให้ใช้ภาษาอังกฤษแบบง่ายและกระชับ
12. หลังจากแยกข้อมูล ให้ตรวจสอบข้อมูลใน Worksheet ปลายทางจริงเทียบกับต้นฉบับ โดยตรวจสอบ:
- จำนวนแถวข้อมูล โดยไม่นับ Header และแถวว่างตามข้อ 2
- จำนวนตัวอักษร โดยใช้หลักการนับเดียวกันทั้งต้นฉบับและปลายทาง
- ความครบถ้วนของข้อมูล เพื่อให้แน่ใจว่าไม่มีข้อมูลขาด เกิน หรือซ้ำ
- การตรวจสอบต้องใช้หน่วยความจำอย่างเหมาะสม
13. เมื่อทำงานเสร็จ ให้แสดงข้อความสรุป:
- จำนวน Worksheet ที่สร้าง
- จำนวนแถวข้อมูลต้นฉบับและปลายทาง
- จำนวนตัวอักษรของข้อมูลต้นฉบับและปลายทาง
- ระยะเวลาที่ใช้เป็นวินาที
- ผลการตรวจสอบเป็น "Passed" หรือ "Failed"
- หากไม่ผ่าน ให้แสดงความแตกต่างที่พบ และระบุตำแหน่งของข้อมูลที่ไม่ตรงกันเท่าที่ตรวจสอบได้
FORMAT
กรุณาส่งผลลัพธ์ดังนี้:
1. VBA Code ที่พร้อมนำไปวางใน Module และใช้งานได้ทันที
2. ขั้นตอนติดตั้งและวิธีรันสำหรับผู้ที่ไม่มีความรู้ VBA
3. อธิบายส่วนสำคัญของ Code
4. ระบุข้อจำกัดและสิ่งที่ควรตรวจสอบก่อนใช้งาน
5. Code ต้องมีการจัดการข้อผิดพลาด และไม่ใช้คำสั่งเลือกหรือเปิด Worksheet โดยไม่จำเป็น
